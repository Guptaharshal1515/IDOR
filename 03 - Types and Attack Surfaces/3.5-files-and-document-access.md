# 3.5 Files and Document Access

Applications often store uploads under an internal ID, filename, or path and expose a download route. If the download handler checks only authentication, a user may retrieve another user’s file by changing the reference.

```text
/download/receipt-1001.pdf
/files/82731
/attachments?attachment_id=44
```

The file endpoint needs its own authorization check. It cannot rely on the page that displayed the link because users can call the URL directly and old links may remain valid after permissions change.

Testing should use harmless test files and review thumbnails, previews, temporary URLs, alternate formats, object-storage permissions, and deleted-file behavior. A random filename reduces guessing but does not replace access control.
